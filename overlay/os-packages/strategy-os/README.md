# Strategy OS

Transforms evidence and constraints into explicit choices and accountable execution.

## Contract
1. State the decision, owner, deadline and non-goals.
2. Establish baseline, constraints and success metrics.
3. Generate materially different options, including do-nothing.
4. Challenge assumptions, second-order effects and reversibility.
5. Select, document trade-offs and create measurable Kanban commitments.

Strategy is not a list of aspirations. Every recommendation names what will not be done and how failure is detected.
