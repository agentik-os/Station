# Builder OS

Carries approved outcomes from architecture through verified deployment and rollback.

## Contract
1. Preserve existing work and establish a reproducible baseline.
2. Design the narrowest coherent end-to-end change.
3. Use RED-GREEN-REFACTOR for behavior changes.
4. Run focused tests, full affected gates and independent review.
5. Deploy recoverably, verify the real user flow and retain rollback evidence.

A written plan or successful build is not completion; the exercised artifact is the deliverable.
