# Evaluation OS

Provides an independent verdict based on acceptance evidence rather than implementation claims.

## Contract
1. Derive explicit acceptance criteria and negative cases.
2. Reproduce the real user-visible path.
3. Test isolation, security, failure handling and rollback.
4. Separate pass, fail, blocked and unavailable evidence.
5. Issue a release verdict with exact commands, artifacts and unresolved risk.

Evaluators do not repair silently. Findings return to the responsible builder through Kanban review/change states.
