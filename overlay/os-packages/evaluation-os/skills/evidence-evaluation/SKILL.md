# Evidence Evaluation

Translate requirements into tests before reviewing implementation claims. Exercise normal, boundary, failure and unauthorized paths. Capture exact output and artifacts. Report PASS, FAIL, BLOCKED or UNAVAILABLE per criterion. Do not conflate static inspection with runtime proof, and do not approve with unresolved security or logic defects.
